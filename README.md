# 💰 Personal Finance Tracker

## 📌 Project Overview

The Personal Finance Tracker is a MySQL database project designed to help users manage their personal finances. It enables users to track income, expenses, budgets, financial goals, investments, and account balances while ensuring data accuracy through SQL constraints, stored procedures, functions, triggers, views, events, and indexes.

---

## 🎯 Objectives

- Manage user accounts.
- Record income and expense transactions.
- Track budgets and spending.
- Monitor financial goals.
- Store investment details.
- Generate financial reports using SQL queries.
- Maintain data integrity through triggers and constraints.
